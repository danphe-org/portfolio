# Nishan Rana Magar — Java Backend Developer Portfolio

Personal developer portfolio for **Nishan Rana Magar**, built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**.

Showcases production backend systems, Spring Boot & Jakarta EE architectures, REST APIs, Docker containerization, and cloud engineering experience.

---

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Backend Core**: Java (Advanced), Spring Boot 4, Jakarta EE, Spring Security, MyBatis, Hibernate
- **Databases & Caching**: PostgreSQL, MySQL, MongoDB, Flyway Migrations
- **DevOps & Cloud**: Docker, Jenkins CI/CD, AWS S3, Maven Multi-Module, Git
